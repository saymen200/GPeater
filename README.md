## О проекте

Российские веб-приложения всё чаще закрыты TLS на ГОСТ-алгоритмах (ГОСТ Р 34.10-2012,
34.11-2012, «Кузнечик» / «Магма») с сертификатами КриптоПро. Обычные `curl`, браузеры и
HTTP-клиенты такие эндпоинты не открывают — их TLS-стек не поддерживает ГОСТ.

**GOST Repeater** — небольшой GUI-репитер (Tkinter): вставляешь «сырой» HTTP-запрос,
правишь его и переотправляешь к серверу за ГОСТ-TLS, ответ смотришь в том же окне.
Историю запросов/ответов инструмент складывает локально. Пригодится разработчикам, QA,
DevOps и интеграторам, которым нужно отлаживать API за ГОСТ-TLS.

## Архитектура

Локальная машина сама ГОСТ-криптографию **не выполняет**. Она лишь формирует запрос и
отправляет его по SSH на подконтрольный хост, где ГОСТ-TLS терминирует `curl` из
дистрибутива КриптоПро:

```
[GUI на твоей машине] --SSH--> [ВМ с КриптоПро CSP] --ГОСТ-TLS--> [целевой сайт]
```

Идея схемы — держать ГОСТ-крипту, сертификаты и решения о доверии на одном
изолированном хосте, который ты контролируешь, а не размазывать их по рабочей машине.
Канал до этого хоста защищён самим SSH.

> Это архитектурная цель, а не гарантия. В частности, по умолчанию используется флаг
> `-k` (проверка серверного сертификата отключена — удобно для отладки, но снижает
> защиту от подмены). Оценивай модель угроз под свою задачу.

## Возможности

- Редактирование и повтор произвольных HTTP-запросов (метод, путь, заголовки, тело)
- Терминация ГОСТ-TLS на удалённом хосте с КриптоПро — без браузера и без КриптоПро на локальной машине
- Локальная история запросов и ответов с быстрым возвратом к предыдущим
- Подсветка статус-кода, время ответа и размер тела

## Требования

- Локально: Python 3.8+ с Tkinter и SSH-клиент
- Удалённый хост (например, виртуалка) с установленным КриптоПро CSP и его сборкой `curl`
- SSH-доступ к этому хосту по ключу

## Настройка

Перед запуском поправь константы в начале `repeater_gui.py` под свою среду:

```python
SSH_TARGET  = "user@vm"                          # твой SSH-хост с КриптоПро
REMOTE_CURL = "/opt/cprocsp/bin/amd64/curl"      # путь к curl от КриптоПро на хосте
```

## Запуск

```bash
python3 repeater_gui.py
```

Формат запроса в окне — обычный «сырой» HTTP: строка запроса, заголовки, пустая строка,
затем тело (пустую строку оставляй даже без тела):

```
POST /api/v1/resource HTTP/1.1
Host: example.gov.ru
Content-Type: application/json

{"key": "value"}
```

## Как это работает

1. GUI разбирает введённый «сырой» HTTP-запрос на метод, путь, заголовки и тело.
2. Собирает из них команду `curl` и выполняет её по SSH на удалённом хосте.
3. `curl` от КриптоПро проводит ГОСТ-TLS-хендшейк с целевым сервером и возвращает ответ.
4. Ответ отображается в окне и сохраняется в локальную историю.

Инструмент не реализует ГОСТ сам — вся крипта остаётся в `curl` от КриптоПро на хосте.

## Ограничения и безопасность

- История сохраняется в открытом виде и может содержать чувствительные данные из твоих
  запросов (заголовки `Authorization`, куки, токены). Не коммить папку истории.
- По умолчанию проверка серверного сертификата отключена (`-k`). Убери флаг, если нужна
  строгая проверка.
- Клиентская авторизация (mTLS) в текущей версии не предусмотрена — только серверный
  ГОСТ-сертификат.
